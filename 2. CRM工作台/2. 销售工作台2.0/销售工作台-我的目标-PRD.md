## 页面总览

**入口**：CRM 销售工作台 → Tab「我的目标」

**布局**：
- 左侧主区：客户目标（汇总 KPI + 五维明细 + 近 9 月趋势）
- 右侧栏：绩效预估 + 绩效排行榜 + 客户排行榜 + 创收排行榜（管理视角另有「切换管理视角」）

**双视角**：
| | 销售视角 | 管理视角 |
|---|---|---|
| 主区数据 | 本人名下 | 团队汇总（可下钻到组/人） |
| 右栏 | 个人绩效预估 + 三类个人相关榜 | 团队绩效预估 + 三类团队榜 + 管理筛选 |
| 风险提醒卡 | 不展示 | 下钻到个人时可展示 |

切换视角后主区、右栏同步切换；视角状态会话内保持。

**统计周期默认**：本月截止到**当日**。管理视角筛选到「组」或「个人」时，改为本月截止到**昨日**，并在模块说明中体现。

## 模块 1：客户目标 · 顶部汇总 KPI

### 做什么
展示 6 张总览卡片，快速看本月整体情况。

### 字段与口径

| 展示名（销售 / 管理） | 口径 |
|---|---|
| 我的客户数 / 团队客户数 | 周期内绑定客户数 |
| 充值客户数 | 绑定客户中完成充值的人数 |
| 交易客户数 | 绑定客户中完成交易的人数 |
| 交易手数 / 平均 | 开仓手数合计 / 人均开仓手数，展示为 `手数 / 平均` |
| 本月联系 / 覆盖率 | 触达人数 / 覆盖率，展示为 `联系数 / xx%` |
| 本月高风险客户数 | 当月高风险客户数（风险样式） |

**汇总覆盖率** = 联系数 ÷ 绑定客户数 × 100（分母为 0 时为 0）。

### 交互
- 模块说明文案末尾「查看指标说明」→ 打开【模块 8】指标说明弹窗。

### 空态 / 异常
- 无数据展示 `0`；接口失败需错误提示 + 重试。

## 模块 2：客户明细 · 客户活跃

### 展示
- 昨日 / 本周 / 本月活跃人数
- 当月 KPI：`本月完成 / 目标`、进度条、实际完成%、核算完成率徽章、档位说明

### 口径
- **活跃标准**：当前客户有充值行为（卡片 `?` 提示）
- **实际完成度** = 本月活跃人数 ÷ 当月目标 × 100

### 核算完成率档位（与净入金共用）

| 实际完成度 | 档位文案 | 核算完成率 |
|---|---|---|
| &lt; 40% | &lt; 40% | 0% |
| [40%, 60%) | 40%～60% | 40% |
| [60%, 80%) | 60%～80% | 60% |
| [80%, 100%) | 80%～100% | 80% |
| = 100% | = 100% | 100% |
| &gt; 100% | &gt; 100% | 按实际（保留 1 位小数） |

进度条宽度 = `min(实际完成度, 100)%`；颜色：档 0 → 灰；40/60 → 中；80/100/超标 → 高。

管理视角标题为「团队客户活跃」，逻辑相同。

## 模块 4：客户明细 · 客户沟通

### 展示字段
| 字段 | 单位 |
|---|---|
| 联系数 | 人 |
| 接通/回复 | 人 |
| CR&lt;2min | 次 |
| TELL&gt;60s | 通 |

### 沟通覆盖率
- 公式：**接通或回复 ÷ 联系数**
- 展示进度条 +「沟通覆盖率 xx%」+ 角标「接通或回复占比」
- 进度条颜色：≥75% 高 / ≥50% 中 / 否则低
- **无核算完成率档位**

> 注意：此处「沟通覆盖率」≠ 顶部汇总的「本月联系覆盖率」（后者是 联系数÷绑定客户数）。

管理视角标题为「团队客户沟通」。

## 模块 5：客户明细 · 交易手数

### 展示
- 昨日 / 本周 / 本月交易手数
- **基础提成核算金额** = 本月手数 × **$0.3 / 手**（单价可配置，默认 0.3）
- 副文案：`按 {手数} 手 × 单价 $0.3/手 核算`
- 本月团队平均手数 = 团队本月总手数 ÷ 团队人数（取整）

### 销售 vs 管理
- **销售**：展示相对团队平均的差值文案（超越 / 持平 / 距离）
- **团队汇总**：只展示团队平均，不展示个人 diff

## 模块 14：切换管理视角（仅管理右栏）

### 级联筛选
1. **一级**：团队所有人 / TW销售A·B·C组 / DANA销售A·B·C组  
2. **二级**：
   - 一级=全员 →「全员汇总」+ 全员名单
   - 一级=某组 →「组内所有人」+ 该组组员

### 解析结果
| 一级 + 二级 | 数据范围 |
|---|---|
| 全员 + 全员汇总 | 团队所有人 |
| 全员 + 某人 | 该销售个人 |
| 某组 + 组内所有人 | 该组汇总（组员指标求和；覆盖率、人均手数再算） |
| 某组 + 某人 | 该销售个人 |

### 联动刷新范围
模块说明、顶部 KPI、五维明细、风险人数、趋势对比说明、右栏绩效预估、绩效榜、客户榜、创收榜。

### 文案
- 提示：`当前管理视角：{标签}`
- 标题示例：团队态「团队客户目标」；个人态「{姓名} · 客户目标」等
